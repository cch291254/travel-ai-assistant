来源编号：S01  
说明：以下路线来自博主截图整理，步行和乘车时间均为截图中的估计值，实际出行前需要使用地图软件重新确认。

- 第一天：西湖 → 打车约15分钟 → 曲院风荷 → 步行约25分钟 → 苏堤春晓 → 步行33分钟→杭鸽餐厅。

- 博主建议：去西湖时导航至断桥残雪，或乘地铁到龙翔桥站；截图称湖滨银泰in77旁可到西湖。

- 截图称京杭大运河杭州景区水上巴士为3元/人、末班18:30，但未注明线路；博主建议想看运河夜景可选择夜游船。

- 博主建议乘船到三潭印月的小岛看湖景。

截图另列出的游览路线：

- 西湖环湖：龙翔桥 → 断桥残雪 → 白堤 → 平湖秋月 → 孤山路 → 西泠桥 → 曲院风荷 → 苏堤 → 花港观鱼 → 太子湾公园 → 雷峰塔 → 长桥公园 → 柳浪闻莺。
- 寺庙参拜：永福寺 → 韬光寺 → 灵隐寺 → 法喜寺 → 法净寺 → 法镜寺。
- 虎跑公园：正门 → 虎跑雕像 → 含晖亭 → 泊云桥 → 天下第三泉 → 钟楼 → 抱翠院 → 宋宴 → 弘一法师纪念馆 → 集雅轩 → 济公塔院。
- 龙井村：村口 → 十八棵御茶树 → 老龙井御茶园 → 十里琅珰观景亭。

截图列出的交通参考：西湖可从地铁1号线龙翔桥站前往；杭州博物馆、河坊街对应地铁1号线定安路站；京杭大运河博物馆对应地铁5号线拱宸桥东站。截图还列出灵隐寺公交7路、法喜寺公交121或103路、虎跑公园公交139路、龙井村公交27路。出行前需重新查询线路。
