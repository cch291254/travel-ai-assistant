# 旧的固定问答流程

项目前三轮评测用的是这条流程。2026-10 底改成由模型选择工具的聊天流程后，它不再被调用，移到这里保存。

## 流程

```text
问题重写（补全指代、判断是否澄清、拆子问题、选来源）
→ 主问题 + 子问题多路检索，按来源过滤
→ 合并去重，交给回答模型
→ 解析 JSON，校验引用编号
```

| 文件 | 原位置 | 作用 |
|---|---|---|
| `rag_pipeline.py` | `app/` | `run_rag`，串起上面的流程，用 `pending_question` 记住待补充的问题 |
| `rag_answer.py` | `app/` | 旧版完整文件，含 `generate_rag_answer` |
| `structured_output.py` | `app/` | 旧版完整文件，含严格 JSON 解析 |
| `streamlit.py` | `app/` | 第一版聊天页面 |
| `run_rag_eval.py` | `examples/` | 前三轮评测脚本 |
| `tests/` | `tests/` | 以上代码的测试 |

`app/api.py` 里调用它的 `call_rag` 已删除。

| 轮次 | 答案正确 | 证据完整命中 | 平均 token/题 |
|---|---|---|---|
| 第一轮（E01–E27） | 15/27 | 16/22 | 3242 |
| 第二轮（E01–E30） | 13/30 | 22/28 | 4936 |
| 第三轮（E01–E30） | 22/30 | 24/29 | 5755 |

详细记录在 `docs/evaluation/history/`。这里的“答案正确”是当时的人工判断，和现在工具聊天用的要点覆盖、依据分口径不同，不能直接比较。

## 为什么换掉

- 固定流程只能问答，不能算价、上网搜索、整理草案，加功能就要改流程。
- 每个问题都要先调一次重写模型，闲聊和计算也不例外。
- 改成工具聊天后，模型自己决定调用哪些工具。

换成工具聊天的第一版漏掉了问题重写，澄清和来源过滤一度失效（基线里澄清类题目要点覆盖 0.42）。后来把重写放进第一次知识库检索，才把这两项补回来。

## 还在用或可以复用的部分

- **还在用：** `app/query_rewriter.py` 的问题重写、`app/rag_context.py` 的证据编号、`app/rag_answer.py` 的回答提示词 `RAG_SYSTEM_PROMPT`。
- **多路检索和去重：** 已经搬到 `app/tools.py` 的 `plan_search` 和 `retrieve_routes`。
- **`pending_question`：** 工具聊天改为靠对话历史承接追问，数据库表还保留着，后续再决定是否删除。
- **严格 JSON 解析：** 如果以后要求回答必须完全符合格式，可以参考 `structured_output.py`。
